# Spiceetech Brand Guidelines

## Identity

|                  |                           |
| ---------------- | ------------------------- |
| **Company name** | Spiceetech                |
| **Slogan**       | Ideas Without Boundaries. |

Company name is always written as one word, capitalized as **Spiceetech**. In the wordmark lockup it is styled as **SPICEE** (dark navy) + **TECH** (sky blue) — see [Logo](#logo).

---

## Color Palette

| Role       | Name      | Hex       | RGB           |
| ---------- | --------- | --------- | ------------- |
| Primary    | Sky Blue  | `#74C9FF` | 116, 201, 255 |
| Secondary  | Maroon    | `#7B1E3A` | 123, 30, 58   |
| Supporting | Dark Navy | `#102A43` | 16, 42, 67    |
| Background | Black     | `#000000` | 0, 0, 0       |

### Usage

- **Sky Blue** — primary accent. Use for the "TECH" half of the wordmark, primary buttons/links, highlights, and the icon mark's light blue shapes.
- **Maroon** — secondary accent. Use sparingly for emphasis, the small accent square in the icon mark, or callouts. Not a dominant color.
- **Dark Navy** — supporting color for the "SPICEE" half of the wordmark, body text on light backgrounds, and the icon mark's dark shapes.
- **Black** — primary background for brand surfaces (site backgrounds, decks, app splash screens). Sky Blue and white text/logo variants should be used on black backgrounds for contrast.
- On light/white backgrounds, use the full-color logo as-is. On black/dark backgrounds, prefer the light logo variant (white or sky blue wordmark) — see [Open Items](#open-items).

## Logo

The Spiceetech mark is an abstract "S/I" monogram built from rounded rectangles in the brand palette, paired with the wordmark.

| Asset                                 | File                                | Use                                    |
| ------------------------------------- | ----------------------------------- | -------------------------------------- |
| Full logo (icon + wordmark + tagline) | `spiceetech-logo-full.png`          | Primary lockup, transparent background |
| Full logo, white background           | `spiceetech-logo-full-white-bg.png` | Use on white/light surfaces            |
| Logo without tagline                  | `spiceetech-logo-icon-wordmark.png` | Compact lockup for headers/nav         |
| Icon mark only                        | `spiceetech-icon-mark.png`          | Transparent, for avatars/badges        |
| Icon mark, white background           | `spiceetech-icon-mark-white-bg.png` | For placement on colored surfaces      |

### Clear space & minimum size

Keep clear space around the logo equal to the height of the "S" in the icon mark. Do not scale the full lockup below ~120px wide or the icon mark below ~32px — detail will be lost.

### Don'ts

- Don't recolor the icon mark outside the defined palette.
- Don't stretch, skew, or rotate the logo.
- Don't place the full-color logo on busy photography without a solid or scrim background.
- Don't recreate the wordmark in a different typeface.

## Typography

The wordmark uses a bold, geometric sans-serif for "SPICEETECH" and a lighter geometric sans-serif for the tagline. No specific typeface has been licensed yet — see [Open Items](#open-items).

## Open Items

These assets were extracted from AI-generated concept renders (raster, ~1448×1086px source), not vector originals. Before production use, consider:

- Recreating the icon mark and wordmark in vector (Figma/Illustrator) for pixel-perfect scaling at any size.
- Producing a dedicated **dark-background / reversed** logo variant (white or sky-blue wordmark) for use on the black background defined above.
- Identifying/licensing the actual typeface used, or selecting a close open-source match.
